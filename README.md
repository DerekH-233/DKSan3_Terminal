## 🤖 诚实的 AI 协作说明

这个站点在很大程度上是"自生长"的。为了保持终端的真实感，我引入了以下 AI 驱动：

* **自主日志 (Autonomous Logs)**：`[ MISSION_LOGS ]` 并非我亲笔所写。系统后台通过 GitHub Actions 每天调用 **DeepSeek** 的 API 接口，在**四段文体规范**（坐标损耗 / 观测目标 / 损耗修正 / 诗意备注）与**防呆板机制**约束下生成。
* **实时共鸣 (Sync)**：AI 每天抓取 **NASA APOD**（每日一图）的科学背景，以 **DKSan3 观察员**身份撰写观测报告——允许 15% 的**感性算法扰动**，为数据注入诗意的杂质。
* **人格升级情境**：每次系统大版本升级后，观察员人格固件同步更新，未来一周的日志会带着"重装后的感官漂移"书写，之后自动回归常态。

## 🛡️ 容错协议

* **链路容错**：与地球的每次握手都允许失败重试，超时即视为信号丢失；标题编译失败时，自动回退原始英文档案，绝不留下空白记录。
* **设备降级**：观测设备能力不足时自动进入低功耗模式；上行链路中断时，回放本地信号缓存，哨站不熄灯。
* **档案卫生**：同一日期绝不写入两条记录，档案库按时间倒序归档并自动裁剪，防止记忆库无限膨胀。
